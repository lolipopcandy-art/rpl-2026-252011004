Panduan Kontribusi
Terima kasih atas minat untuk membantu atau memberi masukan pada repository ini. Untuk menjaga pekerjaan tetap rapi, ikuti panduan berikut.

1. Membuat branch
- Jangan mengubah branch utama secara langsung untuk kontribusi yang memerlukan review.
- Buat branch dengan nama yang menjelaskan pekerjaan, misalnya `docs/perbaiki-readme` atau `fix/perbaiki-typo`.

2. Format commit
Gunakan pesan commit yang singkat, jelas, dan menjelaskan perubahan. Contoh:
- `docs: add AI policy`
- `docs: update repository README`
- `fix: correct broken link`

Awalan yang dapat digunakan:
- `docs:` untuk dokumentasi.
- `fix:` untuk memperbaiki kesalahan.
- `feat:` untuk menambahkan fitur atau bagian baru.

3. Pull request
1. Pastikan perubahan sudah diperiksa dan tidak menghapus bagian yang masih diperlukan.
2. Ajukan pull request dari branch pekerjaan menuju branch utama.
3. Jelaskan apa yang diubah dan alasan perubahan.
4. Cantumkan bukti atau tangkapan layar jika membantu.
5. Tunggu review dan perbaiki masukan yang relevan sebelum perubahan digabungkan.

4. Etika kontribusi
- Gunakan bahasa yang sopan dan berikan masukan yang spesifik.
- Jangan mengunggah kata sandi, token, data pribadi, atau dokumen rahasia.
- Hormati hak cipta dan cantumkan sumber jika menggunakan karya pihak lain.
- Jangan memasukkan perubahan yang tidak berkaitan tanpa penjelasan.
